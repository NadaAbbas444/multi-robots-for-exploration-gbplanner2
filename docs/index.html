Overview

A team of UAVs explores an unknown subterranean or large-scale space, finds objects of interest and builds detailed surface models of them. No central controller is involved: each UAV plans for itself and shares only what its peers need.

Each UAV runs a graph-based planner: a dense local random graph for the next move, and a sparse global graph for repositioning when it hits a dead end or must return home before the battery runs out. Instead of exchanging full maps, UAVs exchange No-Go Zones, volumes around goals they have already visited. A peer may fly through a No-Go Zone, but it never selects a frontier inside one. Detected objects become tasks, distributed by an auction or by fixed explorer and inspector roles. They are then inspected along a shortest tour through viewpoints placed where the object's surface is still unmapped.

System

Components

Local and global planning

An RRG samples collision-free configurations in an adaptive bounding box. Paths with high exploration gain feed a sparse global graph used for repositioning and homing.

No-Go Zones

Uniform volumes around visited goals, shared between UAVs. Frontiers inside them get zero gain, so a peer's explored region is never chosen as a goal again.

Semantic inspection

Unmapped voxels inside the object's bounding box are clustered. Viewpoints near the clusters and with high gain are ordered by the Lin-Kernighan-Helsgaun heuristic.

Task allocation

Sequential auction on travel time, inspection time and workload, respecting each UAV's remaining battery. Role-based allocation is the baseline.

Run it

Everything runs in Docker (ROS Noetic, Gazebo 11, ArduPilot SITL through the LARICS UAV simulation stack). You only need Docker and an X server.

mkdir -p ~/icuas2025_ws/src && cd ~/icuas2025_ws/src
git clone https://github.com/NadaAbbas444/multi-robots-for-exploration-gbplanner2.git
./multi-robots-for-exploration-gbplanner2/workspace/setup_workspace.sh
./multi-robots-for-exploration-gbplanner2/workspace/docker/run.sh

Inside the container:

build_ws
start_sim                              # 2 UAVs, DARPA cave
start_exploration
SCENARIO=tunnel STRATEGY=role start_sim  # semantic inspection, role-based allocation

All options are listed in the README.
